# iClip

原生 Swift / SwiftUI / AppKit 菜单栏剪贴板管理器，无 WebUI，无第三方依赖。

## 功能

- `Ctrl + Shift + V` 呼出紧凑浮窗；搜索、方向键选择、回车选取、Esc 关闭。
- macOS 26 使用系统 Liquid Glass，macOS 14–25 回退为原生材质。尚未验证 macOS 27。
- 置顶永久保存，不受普通历史数量限制。
- 设置中可修改全局快捷键与开机启动。
- 普通历史默认 1000 条，可修改；0 为无限制。编辑后点击“应用”，若会删除旧历史则先请求确认。
- 菜单栏图标提供打开浮窗、设置与退出，可在设置中隐藏（默认显示，重启后记住）。隐藏后快捷键继续有效；应用运行时再次双击同一个 app 会打开设置。设置内也有退出入口。
- 支持文字、文件与图片。文件条目显示「文件」标签和路径，回写文件 URL；图片显示后台生成的缩略图，回写 PNG/TIFF 数据。
- 文件仅保存引用，不备份源文件；移动或删除源文件后可能无法粘贴。图片最多 25 MiB，文字最多 1 MiB；忽略密码管理器常用的 Concealed/Transient/AutoGenerated 标记。
- 数据仅保存在本机，JSON 原子写入在串行后台队列执行。

## 构建

需要 Xcode 26 或以上（Liquid Glass SDK）及 Swift 6。

```sh
swift test
bash scripts/build-app.sh
open dist/iClip.app
```

将生成的 `dist/iClip.app` 复制到 `/Applications` 后使用，尤其是开机启动功能。

Bundle Identifier：`io.github.gamernotitle.iclip`。

默认使用 ad-hoc 签名，适合本地试用；重复构建可能需要重新授权辅助功能。可通过 `SIGN_IDENTITY="Apple Development: ..." bash scripts/build-app.sh` 使用本机正式签名身份。分发时还需 Developer ID 签名与公证。

## 使用与权限

1. 启动应用，菜单栏出现剪贴板图标。
2. 复制文字，按 `Ctrl + Shift + V`，点击条目或回车选取。
3. 在设置里授权“辅助功能”后，选取内容会尝试粘贴至原来的应用；未授权时只复制，请自行按 `Command + V`。若系统中已开启但当前进程仍显示未授权，请完整退出并重新打开同一个 app；用户已验证重新启动后可正确识别权限。
4. 点击条目的图钉置顶；删除按钮会删除该条内容，包括置顶内容。
5. 开机启动由系统 `SMAppService` 管理；若需要审批，在系统登录项设置中允许。

历史与保留数量存储在 `~/Library/Application Support/iClip/history.json`；快捷键存于应用的 UserDefaults。历史文件以仅当前用户读写的 0600 权限保存，但内容仍是明文，没有加密，因此不要将敏感内容置顶。若历史文件损坏，程序暂停保存以防覆盖原文件，备份修复后重启。
