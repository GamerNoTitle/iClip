# 原生应用交互验收

## 已有证据

- `swift test`：29 项 Swift Testing 全部通过。
- 原生独立命名剪贴板集成测试通过：文字、多个文件 URL、PNG/TIFF 回写与读回，NSImage 识别、敏感标记过滤及无效条目不清空剪贴板。测试不访问 general 剪贴板。
- Release 构建、Info.plist 格式检查与 codesign 校验通过。
- codesign 报告 Bundle Identifier 为 `io.github.gamernotitle.iclip`。
- `open dist/iClip.app` 成功，进程检查确认应用已启动。

- 第3轮用户反馈：“正常呼出和选取”。这确认了基本浮窗交互，但并未单独确认辅助功能授权、自动粘贴或登录项。

以上不代表下列全部真实系统交互已通过。

## 待验证

1. 菜单栏图标可打开浮窗、进入设置和退出，应用不出现在 Dock。
2. 在 TextEdit 复制 A、B，Ctrl+Shift+V 打开浮窗；搜索 A，方向键选择，回车选取，Esc 关闭。
3. 未授权辅助功能时，选取条目仅复制；手动 Cmd+V 可粘贴。
4. 用户授权后，选择旧内容自动粘贴到原应用；持有快捷键修饰键时不会错误触发粘贴。
5. 在全屏应用与多显示器上，浮窗保持在当前屏幕可见范围；点击外部关闭。
6. 置顶 A，立即从菜单退出，重新打开，A 仍置顶。
7. 设置快捷键为其他组合，旧组合失效、新组合生效；重启后仍有效。
8. 保留数量初始1000；输入过程中不删除数据，点击应用后生效；会淘汰内容时先确认。
9. 设置0后，超过1000条仍保留；重启后0仍有效；置顶始终不受限制。
10. 将应用放到 Applications 后启用开机启动，检查系统登录项；注销/重新登录后验证启动，关闭后不再启动。
11. 浅色、深色模式检查 Liquid Glass 和文本对比度。
12. 持续复制与反复打开/关闭，检查 CPU、内存与主线程响应，确认无持续彩虹等待。

13. Finder 复制一个或多个测试文件，条目显示「文件」与完整路径，选择后在目标文件夹 Cmd+V 粘贴文件，而非路径文字。
14. 复制 PNG/TIFF 图片，条目显示图片缩略图，选择后在支持图片粘贴的应用粘贴；置顶重启后仍显示与粘贴。
15. 检查浮窗外部不再有方形窗口阴影；设置底部只显示 `iClip · 0.1.0`。

隐私：测试仅用非敏感示例文字，不应抓取或导出用户真实剪贴板历史。辅助功能授权和系统登录项变更须由用户确认。
